# Solves

Solutions, notes, and writeups from competitive programming, CTFs, math practice, and puzzle events.

This repository is mostly a personal archive: code is grouped by platform or event, and individual solutions are usually kept close to the original problem inputs, experiments, and notes.

## Contents

- [`algorithms/`](algorithms/) - Algorithm design problems.
  - [`adventofcode2025/`](algorithms/adventofcode-2025/) - Go solutions for Advent of Code 2025, with per-day folders and livestream links.
  - [`CSES/`](algorithms/cses-problemset/) - CSES.fi problemset solutions
- [`capture-the-flag/`](capture-the-flag/) - CTF notes, challenge files, and exploit scripts.
